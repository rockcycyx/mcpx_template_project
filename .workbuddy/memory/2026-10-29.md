
## S2F33 / S2F35 / S2F37 持久化实现

- 需求：Host 下发 S2F33(定义报表)/S2F35(关联事件报表)/S2F37(使能禁用事件) 后落地持久化到数据库。
- 实现（S2EquipmentService 注入 ISecsReportService/ISecsCeidService/IDbContextFactory，三个方法从"仅校验"改为真正落库）：
  - S2F33 DefineReport：RPTID+VID编号列表 → 映射 VID编号→secs_vid.id，写 secs_report + secs_report_vid。RPTID 已存在则覆盖成员(先 RemoveRange 再重写)；VID 不存在回 DRACK=4。新增时 Name=RPTID 字符串、Status=0。
  - S2F35 LinkEventReport：CEID+RPTID列表 → 映射 RPTID→secs_report.id，写 secs_ceid_report。CEID 不存在自动建 secs_ceid(Name=CEID,Status=0)；RPTID 不存在回 LRACK=5。查询 ceid 需 Include(Reports) 否则导航未加载。
  - S2F37 EnableDisableEvent：CEID列表 → 切换 secs_ceid.status(0=启用/1=停用)。ceids 空列表=作用于全部；指定 CEID 不存在回 ERACK=1。
- 关键：secs_report_vid.vid_id 存的是 secs_vid.id(内部主键)非 vid_id 编号；secs_ceid_report.report_id 存 secs_report.id 非 RPTID。必须做"编号→内部id"映射。
- 编译：CS/MC/XLS 错误=0；MSB3027/3021 是 exe 被运行中进程(PID 22088)锁定，非代码问题。

## 消除 "TabItem.Content 找不到 Frame" 设计器误报

- 现象：VS 设计器报 PageSecsConfig.xaml 134/323/446 行 3 个 TabItem.Content 找不到 Frame（数据上下文 PageSecsConfigViewModel）。
- 根因：MainWindow.xaml 导航 TabControl 的局部隐式 TabItem 样式里 `<Setter Property="Content" Value="{Binding Frame}"/>`，设计器把它错误套用到 PageSecsConfig 的硬编码 TabItem 上（纯设计期误报，编译/运行 0 错误）。
- 修复：给该样式加 x:Key="NavTabItemStyle"，TabControl 用 ItemContainerStyle="{DynamicResource NavTabItemStyle}" 显式引用，使其不再是隐式样式，不再污染其他页面的 TabItem 解析。
- 编译：CS/MC/XLS/MSB 错误=0。

## 首页控制状态胶囊 OnlineRemote 不显示/高亮的根因与修复

- 现象：仅 Online Remote 状态时界面没显示状态（高亮不生效）。
- 根因：PageHome.xaml 控制状态胶囊(Border/TextBlock)的 DataTrigger 用 `Value="5"`/`Value="4"`（字符串），而绑定源 SecsControlState 是枚举(OnlineRemote=5/OnlineLocal=4)。DataTrigger 字符串 "5" 无法经枚举 TypeConverter 匹配枚举值 → 触发器永不命中，胶囊恒用默认颜色；文本绑定 SecsControlStateText 是纯字符串，其实能显示 "OnLine Remote"。
- 修复：DataTrigger 的 Value 改为枚举名称 `OnlineRemote`/`OnlineLocal`（枚举 EnumConverter 能按名称转换，正确命中）。
- 编译：exit 0，无错误。
