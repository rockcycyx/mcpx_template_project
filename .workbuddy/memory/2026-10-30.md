## PageTrigger 状态列「未正常渲染」修复 + S5F3 加固 + BuildAlcd 断点

### 渲染问题（同昨晚同类：显式 Style 覆盖 inkore 隐式主题）
- 现象：PageTrigger 列表「状态」列事件 ToggleSwitch / 警报类别 ComboBox 未正常渲染。
- 根因：给 ui:ToggleSwitch / ComboBox 显式声明了 `<Style TargetType="...">`（在 .Style 属性里，用 DataTrigger 切 Visibility），该 Style 无 BasedOn，覆盖 inkore 全局 Fluent 隐式样式 → 控件丢失 Fluent 外观。
- 修复：去掉 Style+DataTrigger，改用 Visibility 直接绑定转换器。PlcTrigger 实体补 `IsEvent`（NotMapped，与 IsAlarm 对称）；ToggleSwitch 用 `Visibility="{Binding IsEvent, Converter=BooleanToVisibilityConverter}"`，ComboBox 用 `IsAlarm`。

### S5F3 加固
- `aledItem.FirstValue<byte>()` 在 ALED 空 item（Count=0）时可能抛异常；补 `aledItem.Count == 0 → enable=false` 的短路，避免空值求 FirstValue。

### BuildAlcd 断点走不进
- 根因：短方法被 JIT 内联，Debug 断点命中不了（非代码逻辑错误，逻辑本身正确，`return query.ToList()` 会触发 Select 执行）。
- 修复：BuildAlcd 加 `[MethodImpl(MethodImplOptions.NoInlining)]` 阻止内联，保证断点可命中。

- 编译：exit 0。

- 改动：

  - DatabaseInitializer：recipe 补列 program_content → 改为 ccode（`EnsureColumn(db,"recipe","ccode","TEXT")`）。

  - IS7ProcessProgramService：删掉 ProcessProgramCommand/ProcessProgram record 与 StoreFormattedProgramAsync；新增 `ProcessProgramData(Ccode, Params)` record、`StoreProcessProgramAsync(ppid, ccode, IReadOnlyList<Item>)→byte`、`GetProcessProgramAsync(ppid)→ProcessProgramData?`。
