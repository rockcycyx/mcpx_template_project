## 三处 UI 调整（Fluent TreeView / 首页去重 / 移除页签加号）

1. **SECS 配置页左侧树改用 FluentUI 样式**：`PageSecsConfig.xaml` 给 TreeView 的 `ItemContainerStyle` 加 `BasedOn="{StaticResource DefaultTreeViewItemStyle}"`（iNKORE `ThemeKeys.DefaultTreeViewItemStyleKey` 是 `public static readonly string = "DefaultTreeViewItemStyle"`，不是 ComponentResourceKey）。坑：`{x:Static ui:ThemeKeys.DefaultTreeViewItemStyleKey}` 报 MC2000 "Value cannot be null (Parameter 'key')"，直接写字符串字面量 `{StaticResource DefaultTreeViewItemStyle}` 即可。
2. **首页去重**：`MainWindowViewModel.NavigateToMenu` 拦截 `HomePageType`，命中则 `SelectedTab = Tabs[0]`（复用 InitializeHomeTab 创建的自带首页），不再新建可关闭的「主页」tab。
3. **移除页签加号**：`MainWindow.xaml` 的 TabControl 加 `ui:TabControlHelper.IsAddTabButtonVisible="False"`（iNKORE 给原生 TabControl 挂的 Fluent TabView 特性，附加属性 `TabControlHelper`）。

### 关键结论
- iNKORE 0.10.2.1 无独立 `Controls.TreeView` 类型，TreeView 样式直接作用于原生 `System.Windows.Controls.TreeView/TreeViewItem`，通过 `ThemeKeys.DefaultTreeViewItemStyleKey`（字符串 "DefaultTreeViewItemStyle"）引用。
- TabControl 的「加号」是 iNKORE `TabControlHelper.IsAddTabButtonVisibleProperty` 附加属性（默认可见），隐藏用 `ui:TabControlHelper.IsAddTabButtonVisible="False"`。

用户 5 点需求（编号有重复），全部完成：

3. **树格式 `类型 值：名称`**：树节点标题改为 `SVID 1：温度`、`RPTID 5：xxx`、`CEID 3：xxx`（`$"{VidType} {VidId}：{Name}"`）。
4. **表格加设备代号列**：VID DataGrid 加 `DeviceCode` 列。
5. **查询参数扩展 + 状态开关**：`QueryPagedAsync` 扩展为 `(vidType, keyword, deviceCode, plcAddress, status, paging)`，BuildQuery 加 DeviceCode/PlcAddress Like + Status 精确过滤。状态列改用 `ui:ToggleSwitch` + `StatusToBoolConverter` 显示（不再显示 1/0）。

### 关键决策：Status 语义统一
- 原 SECS 三实体（Vid/Report/Ceid）Status 用 `"1"=启用,"0"=停用`，与系统全局（Role/User/Menu 等 `"0"=正常/启用`）及 `StatusToBoolConverter`（`true="0"`）**相反**。
- 为让 `StatusToBoolConverter` 正确显示（开=启用），统一三实体 Status 为 `"0"=启用,"1"=停用`：实体注释+默认值 `"0"`、三个 Service Normalize 改 `Status=="1"?"1":"0"`、树判断 `Status=="1"`→`"0"`、三个弹窗状态 ComboBox Tag 交换（启用=0/停用=1）、三个 FieldViewModel 默认 Status `"1"`→`"0"`。

### 注意
- 旧库已有 `secs_vid.status`/`secs_report.status`/`secs_ceid.status` 数据语义仍为旧值（1=启用），统一后旧数据语义会颠倒。建议对旧库执行一次 `UPDATE ... SET status = CASE status WHEN '0' THEN '1' WHEN '1' THEN '0' END`，或重建库。

### 关于 StatusToBoolConverter 语义
用户质疑「为什么 0=正常，反了」。确认：这是**系统全局约定**（SysUser/SysRole/SysMenu/SysDept/SysPost 全部 `"0"=正常/启用，"1"=停用`），`StatusToBoolConverter`（`true="0"`）与系统一致，被后台管理模块广泛使用，**不能改**。SECS 侧保持与系统统一的 `"0"=启用`，状态显示改用胶囊按钮 + DataTrigger 直接映射，不再依赖该转换器。
